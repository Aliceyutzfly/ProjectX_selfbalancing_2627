# Original third-party library archives

These ZIP files contain all four required third-party libraries with their original metadata and notices. Their active, compiled copies are already bundled in ../src/lib, with relative includes adjusted for Arduino IDE's sketch build. No manual library installation is required. Do not add a second copy of these sources to the sketch root; that can cause duplicate definitions. WiFi, WebServer, Preferences, Wire, USB/FreeRTOS and standard headers come from the ESP32 board package, not these archives.
